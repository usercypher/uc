## Notes
- Timestamps: Store as INTEGER for fast queries. Any range query can use integer with mapping for optimal performance.
- AUTO_INCREMENT: MySQL/SQLite use this keyword; PostgreSQL uses SERIAL or GENERATED (database-specific).
