uc.css

A lightweight semantic CSS framework focused on readable content, minimal styling, and production-ready HTML.

Home | Documentation | Examples | Download | GitHub

Content First

Modern HTML already contains most of the structure needed to build beautiful websites. uc.css styles the HTML you already write instead of requiring dozens of utility classes.

You can mix strong, emphasis, HTML, inline code, Ctrl + S, x, 2, H2O, citations, and quoted text naturally.

Semantic HTML should be enough for most websites. Classes should enhance markup, not replace it.

Why semantic CSS?

Most websites are documents with navigation, images, tables, forms, and articles. Styling those elements well provides a surprisingly complete design system while keeping HTML clean and maintainable.

Did you know?

The browser already understands many HTML elements. Good CSS simply enhances those defaults.
